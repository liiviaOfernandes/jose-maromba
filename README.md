# Maromba Duo — Web App

Aplicativo web mobile-first com dois perfis independentes: José e Livia. Cada usuário tem sua própria ficha, calendário semanal, cargas, preferências e histórico.

## Recursos
- Dois logins personalizados.
- Treinos diferentes por perfil.
- Timer automático após cada série com 45 s, 60 s, 90 s e 120 s.
- Pausar, reiniciar e pular o intervalo.
- Som e vibração ao terminar o descanso.
- Popup de demonstração em vídeo ou busca pronta no YouTube.
- Registro de cargas por exercício.
- Histórico de treinos concluídos separado por perfil.
- Tema personalizado por usuário.
- PWA instalável quando hospedado em HTTPS.

## Divisão do José

- Ter: B
- Qua: Cardio + Abdômen
- Qui: A
- Sex: B
- Sáb: Superiores completo
- Dom: descanso

## Divisão da Livia
- Seg: A — Pernas e Glúteos
- Ter: B — Costas, Ombros e Braços
- Qua: Abdômen
- Qui: C — Posteriores e Glúteos
- Sex: A
- Sáb/Dom: descanso

## Como testar
Abra com Live Server no VS Code, Laragon, XAMPP ou outro servidor local.

> Segurança: o login desta versão é feito no navegador. Para publicação pública com autenticação real, migre usuários e senhas para um backend (PHP/Node etc.) com banco de dados e sessão segura.
